# Demo persona fixtures (Ben Health OS)

> **ALL DATA IN THIS DIRECTORY ARE SYNTHETIC.** They are generated by a
> seeded pseudo-random script and describe a fictional "demo" persona.
> No real person, no real device, no real health data. Never replace these
> files with real measurements.

These fixtures back demo mode (`PLATFORM_MODE=demo`, `POST /demo/seed`,
`WithingsFake`) and the platform test suite. Shapes follow
`docs/contracts/phase1-contracts.md` (normative).

## Contents

Ninety days of blood-pressure data ending **2026-08-28**, timezone
**America/New_York** (entire window is EDT, UTC-04:00):

| File | What it is |
| --- | --- |
| `bp-withings.json` | 427 Withings measure groups (one BP reading each: types 10/9/11 = systolic/diastolic/pulse, unit 0) across 170 sessions — ~2 sessions/day (morning ~07:30, evening ~21:15), 2–3 readings per session 60–120 s apart, ~12% of days missing one session, first-of-session and evening biases, and a gentle +4 mmHg systolic drift over the last 30 days. |
| `bp-withings-corrections.json` | Exactly one corrected measurement: reuses an existing `grpid` with a later `modified` and systolic changed by −8 (tests correction handling / re-delivery). |
| `bp-apple-health.json` | HealthKit-shaped samples: 30% of the Withings groups mirrored exactly (Health Mate / BPM Connect — cross-source duplicates), 6 non-duplicate Qardio readings on separate days, and 3 samples with `pulse: null` (never-zero rule). |
| `bp-manual.json` | 4 `ManualBpEntry` objects (contracts §5); the first exactly matches a Withings reading's time and values (manual-vs-device dedup case). |
| `webhook-notifications.json` | 5 Withings-style notifications (`appli: 4`) aligned to the last 5 Withings sessions, plus one exact duplicate of the last (webhook idempotency case). |

## Regenerating

```sh
node generate.mjs
```

The generator is fully deterministic (mulberry32 PRNG, seed 42, hardcoded
end date, no npm dependencies) — reruns produce byte-identical files. It ends
by verifying its own invariants (unique grpids, value ranges, the correction,
duplicate mirrors, null-pulse count, webhook duplicate) and throws if any
break. Commit the regenerated JSON alongside any change to `generate.mjs`.
